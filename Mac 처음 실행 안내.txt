Mac 처음 실행 안내
==================

"fgma.app"를 더블클릭하면 f(g)=ma 포스터 제너레이터가 실행됩니다.

처음 실행 전 준비
----------------

1. Node.js가 설치되어 있지 않다면 https://nodejs.org 에서 LTS 버전을 설치합니다.
2. 프로젝트 폴더에서 "fgma.app"를 더블클릭합니다.
3. 처음 실행할 때 필요한 패키지가 자동으로 설치될 때까지 기다립니다.
4. 포스터 제너레이터가 브라우저에서 열립니다.

macOS 보안 경고가 뜨는 경우
--------------------------

"fgma.app" 또는 "Start Poster Generator.command"를 열 때 아래와 같은 경고가 뜰 수 있습니다.

Apple은 이 파일에 악성 코드가 없음을 확인할 수 없습니다.

이 경우 터미널을 열 필요 없이 Finder에서 이렇게 실행하세요.

1. "fgma.app"를 Control-클릭하거나 오른쪽 클릭합니다.
2. "열기"를 선택합니다.
3. 경고창이 다시 뜨면 "열기"를 한 번 더 누릅니다.
4. 다음부터는 더블클릭으로 실행할 수 있습니다.

왜 이런 경고가 뜨나요?
----------------------

macOS는 인터넷에서 받은 앱과 실행 파일에 보안 표시를 붙입니다. 이 프로젝트의 앱은
Apple에 등록된 개발자 계정으로 서명하고 공증한 앱이 아니기 때문에, 처음 실행할 때
Gatekeeper가 사용자 확인을 요구할 수 있습니다.

다른 사람의 Mac에서도 완전히 경고 없이 더블클릭으로 실행되게 하려면, 이 프로젝트를
Apple Developer 계정으로 서명하고 공증한 macOS 앱 형태로 배포해야 합니다.
