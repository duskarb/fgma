Windows 처음 실행 안내
=====================

"Start fgma.bat"을 더블클릭하면 포스터 제너레이터가 실행됩니다.

처음 실행 전 준비
----------------

1. Node.js가 설치되어 있지 않다면 https://nodejs.org 에서 LTS 버전을 설치합니다.
2. 프로젝트 폴더에서 "Start fgma.bat"을 더블클릭합니다.
3. 처음 실행할 때 필요한 패키지가 자동으로 설치될 때까지 기다립니다.
4. 브라우저가 자동으로 열리고 포스터 제너레이터가 실행됩니다.

Windows 보안 경고가 뜨는 경우
----------------------------

인터넷에서 받은 .bat 파일이라 Windows SmartScreen 또는 보안 경고가 뜰 수 있습니다.

1. "Windows의 PC 보호" 창이 뜨면 "추가 정보"를 누릅니다.
2. "실행"을 누릅니다.
3. 이후 뜨는 검은 실행 창은 닫지 마세요. 이 창을 닫으면 앱도 종료됩니다.

왜 이런 경고가 뜨나요?
----------------------

Windows는 인터넷에서 받은 실행 파일이나 배치 파일을 조심스럽게 다룹니다. 이 파일은
포스터 제너레이터를 실행하기 위해 npm 설치, 빌드, 로컬 서버 실행 명령을 자동으로
실행합니다.

한 번만 승인하면 이후부터는 더블클릭으로 바로 실행됩니다.
